# Hyreflow plugin

The installable plugin package: four Agent Skills (`skills/`), an approval hook (`hooks/`) that
auto-approves only read-only, non-spending `hyreflow` CLI commands, and the manifests each harness
reads (`.codex-plugin/`, `.claude-plugin/`, `.cursor-plugin/`, `plugin.json`).

Install instructions, the MCP connection table and the client-by-client setup live in the
[repository README](../README.md) and at https://hyreflow.ai/docs/mcp-setup.
