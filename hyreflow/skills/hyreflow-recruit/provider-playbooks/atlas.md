# Atlas — Integration Meta Skill

HOW in `lib/atlas.py`.

## Auth & config
- **Base URL:** `https://api.recruitwithatlas.com/api/v1` · **Auth:** header `Authorization: Bearer <JWT>` (env `ATLAS_API_KEY`; never hardcode). `list_projects()` = safe read-only pilot.
- **ALL paths CONFIRMED** from the official OpenAPI 3.1 spec (recruitwithatlas.com, pasted by user in the ENG-229 Linear thread, 2026-07-14). Full endpoint index: `reference/docs/atlas/raw/endpoints.md`.
- Atlas terminology: **person** (one record, many roles — candidate/contact/lead), **company**, **contact** (= a `company_contacts` junction, at most one live per person), **project** (= job), **candidate** (= a person's candidacy within a project's pipeline), **opportunity** (= deal), **placement**.

## Operations (25 methods; long tail via `request()`)
Companies (dedup/enrichment): `list/get/find/create/update_company`. Contacts: `list_contacts`. People
(candidates/leads): `search/lookup_people`, `get/create/update_person`, `add_person_note`. Projects
(jobs): `list/get/create_project`, `list_project_stages`, `list_project_candidates`,
`add_candidate_to_project`, `add_project_applicant`, `move_candidate_to_stage`. Candidates (agency-wide):
`list_candidates`. Opportunities (deals): `list/get/create_opportunity`, `list_opportunity_stages`.
Everything else (campaigns, meetings, interviews, fees, files, placements, users, custom-attributes,
identities, experiences) → `request()`; all listed in the cached index.

## Guardrail
Writes go to a production ATS/CRM — pilot one record, show payload + response, confirm before bulk.
`create_person` is a **strict create** — it never merges into an existing record. If any identity
(email/phone/LinkedIn) already matches a person, it 409s with that person's `personId` — switch to
`update_person` (PATCH) instead of retrying the create.

## Handoff
ATS write target: sourced+enriched candidates/leads → `create_person` (or `lookup_people` first to avoid
a 409) → `add_candidate_to_project` to land them in a project's pipeline → review in Atlas. Companies
sourced as targets → `find_company` (dedup) → `create_company` if no match → `create_opportunity` /
`create_project` to open a deal or a role against them.

## Bulk writes & rate limits

For large pushes use `create_people_batch`, `create_companies_batch`, `create_projects_batch` and
`create_opportunities_batch`. They pace calls to a conservative **60 req/min** default and return
`{created, failed, total, elapsed_ms}`. Override with `ATLAS_RATE_LIMIT_RPM`. See `crm-bulk-pushes.md`
for the cross-CRM guide.
