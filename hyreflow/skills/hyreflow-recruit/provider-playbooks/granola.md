# Granola — Integration Meta Skill

HOW in `lib/granola.py`. OpenAPI cached at `reference/docs/granola/raw/openapi.md`. **Read-only** (no writes).

## Auth & config
- **Base URL:** `https://public-api.granola.ai` · **Auth:** header **`Authorization: Bearer <key>`** (key format `grn_…`, env `GRANOLA_API_KEY`; never hardcode).
- **Plan/scopes:** requires a Granola **Business** plan; keys carry **Personal notes** and/or **Public notes** scopes (set when the key is created) — a key only sees notes in its granted scopes.
- **Rate limit:** 25 burst / 5s, 5/s sustained (300/min) → `429`. `list_folders(page_size=1)` = safe read-only pilot.
- **No credit metering** — it's a flat API (rate-limited, not credit-billed).

## ⚠️ Only summarized notes are visible
The API returns **only notes that have a generated AI summary AND transcript.** Still-processing or never-summarized notes are **excluded** from List and **404** on Get. So "missing" notes usually = not-yet-summarized, not an error.

## Operations
- **`list_notes(created_after=, created_before=, updated_after=, folder_id=, page_size≤30)`** → `{notes:[{id 'not_…', title, owner, created_at, updated_at}], hasMore, cursor}`. Dates accept `YYYY-MM-DD` or ISO datetime. `folder_id` (`fol_…`) includes child folders.
- **`get_note(note_id, include="transcript")`** → full note: `summary_text`, `summary_markdown`, `attendees[]`, `calendar_event` (title/organiser/scheduled times/invitees), `folder_membership[]`, `web_url`, and (with `include`) **`transcript[]`**. Use the **`not_…` id** from list (not a UUID). Convenience: **`get_note_transcript(note_id)`**.
- **`list_folders(page_size≤30)`** → `{folders:[{id 'fol_…', name, parent_folder_id}], hasMore, cursor}`. `parent_folder_id` null = top-level.
- **Pagination:** cursor-based (`hasMore` + `cursor`). `iter_notes(**filters)` / `iter_folders()` auto-walk it (bounded by `max_items`). Anything else → generic `request("GET", path, params=...)`.

## Transcript shape (read carefully)
`transcript[]` items = `{speaker:{source, diarization_label?}, text, start_time, end_time}`.
- **macOS:** `speaker.source` ∈ `microphone` (local mic) | `speaker` (other meeting audio) — two-stream, so you can separate "us" vs "them."
- **iOS:** `source` is always `microphone` (single stream); speaker identity comes from **`diarization_label`** (`Speaker A`/`B`/…) when diarization is available.
- Don't assume `source` distinguishes people on iOS — use `diarization_label` there.

## Handoff
Post-call intelligence layer: pull a call's `summary_markdown` + `transcript` → feed BD/candidate research, follow-up drafting, or signal extraction. Read-only source; no outreach side-effects.
