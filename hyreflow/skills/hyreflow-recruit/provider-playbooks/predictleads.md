# PredictLeads Guidance

Use PredictLeads for company-level signals: hiring, technology detections, news events, financing events, connections, products, GitHub repositories, and similar companies.

Prefer direct company endpoints (including `similar_companies`) when you already have a domain — they bill a flat rate per request (0.8 credits) regardless of record count, up to 1,000 records on list endpoints. Discovery (`discover_*`, `iter_discover_*`) endpoints bill per returned record instead (0.8 credits each, so a full `limit: 50` page is 40 credits); the `--dry-run` quote is `limit` × that rate (`limit` defaults to 100; `max_records` for `iter_*`, at most 500 per call), so use them only when you need broad search across companies rather than a single known domain. Check `hyreflow tools get predictleads <method>` for the live rate on each.

A row carries its company's domain and name as flat columns, named after the link: `company_domain`
/ `company_name` on job openings, financing events and most others, plus `similar_company_domain` on a
lookalike, and `company1_domain` / `company2_domain` on news events and connections. Read the hirer from
these, not from a listing URL. A funding round's `investors` stay ids only. The columns appear only when
PredictLeads returns that company alongside the row; if `company_domain` is missing or empty, resolve
`relationships.company.data.id` with `predictleads company`.

Avoid follow/unfollow workflows for now. PredictLeads followed-company APIs are designed for webhook delivery and recurring monthly billing, not one-shot agent execution.

## Job openings — field notes
- `job_openings`: pass `limit: 1000` — the flat per-request price above covers up to 1,000 rows, so a
  small limit saves nothing (you'd just page more). Add `last_seen_at_from` to skip history older than
  you need.
- Filter roles on their **title**, not on `categories` or the per-row `onet_data.code` — both
  misclassify (a service advisor can land under `support`, a pricing lead under `management`). O*NET
  codes belong in the `discover_job_openings` query, not in row filtering; see
  [`../recipes/repost-signal-to-bd.md`](../recipes/repost-signal-to-bd.md) for the title → O*NET
  resolution step.
- Check the company's `meta` for `parent_company_domain`, subsidiaries and `redirects_to_domain`, and
  pull those domains too — e.g. `acme.nl` vs `acme.com`, or `acme.de` vs `acme-direct.de` can be the same
  employer split across domains.
- `posted_at` and `status` are usually empty — derive open/closed and the listing's age from
  `first_seen_at`/`last_seen_at` instead.
- `discover_job_openings` needs `onet_codes` or it times out scanning everything — see
  [`../references/field-notes.md`](../references/field-notes.md) (O*NET section) for turning a title into
  a code.
- `location` on `discover_job_openings` (and `location` / `company_location` on every other
  `discover_*` / `iter_discover_*` method) takes ONE country by its full name, or ONE state by name or
  abbreviation: `"United States"`, `"Tennessee"` or `"TN"` — not a country code like `"US"`. A combined
  `"Tennessee, United States"` fails with `Invalid location`; pass the state alone when you want a state.
  The vendor allows no city: for "hiring in Nashville", pass the state and keep the rows whose
  `attributes.location` names the city.
- `crawler_potentially_blocked: true` on a company means its coverage is incomplete — say so in any
  output built from it, rather than reporting a clean result off partial data.
- Detecting a **reposted**, **long-open** (live 90+ days) or **evergreen** (relisted monthly) role from a
  company's history is its own recipe: [`../recipes/repost-signal-to-bd.md`](../recipes/repost-signal-to-bd.md).

## Callable surface
Call via the CLI: `hyreflow tools execute predictleads <method> --payload '{...}'` (preview with `--dry-run`; `hyreflow tools get predictleads <method>` returns the live contract + cost). Base: `https://predictleads.com/api/v3`. Only the methods listed below are callable.

- `api_subscription() -> Any` — GET /api_subscription — subscription status + monthly credit quota/used on the caller's own PredictLeads account; requires the workspace's own key.
- `company(identifier: str, **params) -> Any` — GET /companies/{domain_or_id} — one company (name, location, ticker, parent, similar). CONFIRMED.
- `connections(identifier: str, **params) -> Any` — GET /companies/{id}/connections — partner/vendor/integration/investor/parent connections.
- `discover_companies(*, limit: int = 100, **params) -> Any` — GET /discover/companies — discover companies by `location` + `sizes` (e.g. ['11-50','201-500']).
- `discover_financing_events(*, limit: int = 100, **params) -> Any` — GET /discover/financing_events — discover funding rounds by `financing_types_normalized` (e.g. ['series_a','series_a1']) + `company_location`, ordered by updated date. Per result. CONFIRMED.
- `discover_job_openings(*, limit: int = 100, **params) -> Any` — GET /discover/job_openings — discover openings by `onet_codes` (O*NET, e.g. '15-1252.00' software devs, '41-3091.00' sales) + `location`. Per result. Filters by O*NET occupation, NOT free-text title.
- `discover_news_events(*, limit: int = 100, **params) -> Any` — GET /discover/news_events — discover news events by `categories` + `company_location`. Per result. CONFIRMED.
- `discover_portfolio_companies(*, limit: int = 100, **params) -> Any` — GET /discover/portfolio_companies/connections — portfolio companies of VCs/accelerators (investor connections). Per result. Filters: first/last_seen_at_from/until. CONFIRMED.
- `discover_products(*, limit: int = 100, **params) -> Any` — GET /discover/products/latest — latest products by `sources` (['menu','pricing']) + date. Per result. CONFIRMED.
- `discover_startup_platform_posts(*, limit: int = 100, **params) -> Any` — GET /discover/startup_platform_posts — Hacker News Show/Job posts (hiring/launching). Filters: published_at_from/until, post_types (['show_hn','job_hn']). Per result. CONFIRMED.
- `discover_technology_detections(technology_id_or_fuzzy_name: str, *, limit: int = 100, **params) -> Any` — GET /discover/technologies/{tech_id_or_fuzzy_name}/technology_detections — companies using a specific technology (e.g. 'HubSpot'). Per result. CONFIRMED. Resolve the tech via technologies().

- `followings(**params) -> Any` — GET /followings — companies you follow (for webhook delivery). 1 PredictLeads credit (vendor-side; hyreflow's price is this method's `cost` block). CONFIRMED.

- `get_job_opening(opening_id: str, **params) -> Any` — GET /job_openings/{id} — a single job opening by UUID. CONFIRMED.
- `get_news_event(event_id: str, **params) -> Any` — GET /news_events/{id} — a single news event by UUID. CONFIRMED.
