# hyreflow-agent — AI reasoning Native

HOW in `lib/hyreflow_agent.py`. Prompt cookbook in `prompts.json` (skill root).

## What it is
A hosted LLM you invoke to do model work on a row or task, with two entry points:
- **`infer(prompt, schema=…)`** — *plain* model call, **no tools**. Classify / extract / score / write. Cheap.
- **`research(prompt, schema=…)`** — *agentic*: model **+ a toolbelt of hyreflow adapters** in a tool-calling loop, for open-ended research / signal extraction / synthesis.

It does research (with tools) + plain inference. Pass a JSON `schema` to force structured output; `{{placeholders}}` in a prompt are filled from row data by the caller.

## Toolbelt (what `research()` may call)
Bound to real adapters (verify bindings on first pilot):
- `exa_search(query)` → `exa.search` — neural/semantic web search — **use first**; best recall on an open-ended research question.
- `serper_search(query)` → `serper.search` — Google SERP — for `site:`-scoped or exact-string lookups, and to fill gaps Exa leaves.
- `firecrawl_scrape(url)` → `firecrawl.scrape` — scrape ONE known URL to markdown — only after you know the page.

## Metering & class
- **First-party Native — no BYOK, always credit-metered.** Cost = **model tokens + any tool calls** the agentic loop makes, billed post-call from actual returned usage as a pure pass-through of the underlying model's list price (no markup). Runs on hyreflow's managed key, server-side in production.

## When to use it — and when NOT
- **In interactive Model A, the host agent does this reasoning for FREE — the agent you're already paying for.** Reach for this Native for **batch / headless / scale**: per-row over thousands of rows, or scheduled/automated runs with no agent present.
- **Don't** use it for **deterministic** work (formatting, dedupe, templating) → that's plain Python / `cli.py`, free.
- **Don't** use it for **mechanical fields** (emails, firmographics, titles) → call the **direct data adapter** (cheaper, cleaner).
- **Don't** start `research()` for something a search adapter answers directly — resolve domains/pages with `serper`/`exa` first.
- Inside `research()`: **cheap Serper first → Exa only if gaps** (an Exa search is charged at twice a Serper one, and asking it for more results costs more again); scrape only known URLs; keep it tight — every inner call is metered at its own rate.
- **Split passes:** one `research()` to gather facts → a separate `infer()` to classify/score/write from that column.

## Prompt cookbook (`prompts.json`)
Before writing a fresh prompt, **check the cookbook** — reusable, parameterized recruiting templates (qualify-against-role, summarize-profile-vs-job, classify-seniority, extract-skills, candidate/BD first-lines, open-to-work signals, ICP fit, sequence outline, agentic company research).
- List: `hyreflow tools execute hyreflow-agent list_prompts --payload '{}'` · load one: `hyreflow tools execute hyreflow-agent get_prompt --payload '{"name": "Qualify candidate against role"}'` · or `grep`/`jq` the file.
- Bind the template's `{{slots}}` to the row, then pass to `infer`/`research`.

## Handoff
Feeds the qualify gate and outreach: `research()`→facts column → `infer()`→tier/first-line → sequencer/ATS. Keeps the metered AI step explicit and gated; the free interactive path stays on the host agent.
