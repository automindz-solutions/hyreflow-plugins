# Lusha — Agent Guidance

## When to use

Lusha for B2B email + direct dial enrichment. Strong North American and European coverage with intent signal data. Good for sales prospecting workflows where direct dials matter. Email and phone are separate methods at separate prices — reach for `lusha_enrich_person_email` unless the play needs to dial; check `hyreflow tools get lusha enrich_person_email` for the live cost.

**Key strength**: Direct dials (not just HQ numbers). Lusha often surfaces mobile and desk direct numbers that other providers miss.

## Provider characteristics

- **Input required**: LinkedIn URL (best), email, or first_name+last_name+(company_name or company_domain)
- **Geographic coverage**: Global, strongest in North America + Europe
- **Credit cost**: per revealed record, set by the method you call — an `*_email` method bills the base
  rate, a `*_phone` method several times more (a phone reveal costs Lusha 5x an email one). Company
  enrich is a flat rate. Lusha charges per call whatever it returns, so a 0-result search still bills.
  A handful of filter/catalog/usage lookups are free
- **LinkedIn URL requirement**: Must contain "linkedin.com/in/". Sales Navigator URLs not supported.

## Key operations

### lusha_enrich_person_email / lusha_enrich_person_phone

Enriches a person by LinkedIn URL (preferred), email, or name+company. The email method returns emails at
`emails[].email`; the phone method returns direct dials at `phones[].number`. Same arguments either way —
the field, and therefore the price, is the method's.

```json
{
  "linkedin_url": "https://www.linkedin.com/in/johndoe"
}
```

```json
{
  "first_name": "Jane",
  "last_name": "Smith",
  "company_domain": "acme.com"
}
```

There is no field argument: an email-only play cannot be billed the phone rate, and asking for a dial is
an explicit choice of method.

Intent signals come from `lusha_contact_signals` / `lusha_company_signals`, not a flag on enrich.

### lusha_enrich_company

Enriches a company from domain, name, or Lusha company ID. Returns size, revenue, industry, technologies.

```json
{
  "domain": "salesforce.com"
}
```

### lusha_search_contacts

Prospecting search with rich filters: department, seniority, company size, industry, job title, location, and tech stack.

```json
{
  "filters": {
    "seniority": ["director", "vp", "c_suite"],
    "companySize": ["201-500", "501-1000"],
    "department": ["sales"]
  },
  "pageSize": 25
}
```

## Output shape

`lusha_enrich_person_email` returns email at `emails[0].email` or `email`; `lusha_enrich_person_phone` returns phone at `phones[0].number` or `phone`.

`lusha_enrich_company` returns a flat company object with `name`, `domain`, `size`, `industry`, `technologies[]`.

`lusha_search_contacts` returns `{ contacts: [...], pagination: { page, pageSize, total, totalPages } }`.

## Anti-patterns

- Don't use Sales Navigator or Recruiter LinkedIn URLs — they'll fail
- Don't include "http://" or "www." in domain values for company enrichment
- Don't pass `company_name` alone without `first_name` + `last_name` for person lookup — name+company is the minimum combo
- Don't assume `phone` (top-level) is always populated — check `phones[]` array first for the most complete list
